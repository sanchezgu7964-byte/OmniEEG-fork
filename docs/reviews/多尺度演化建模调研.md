# 多尺度演化建模调研（世界模型方向）

> 2026-11-14。按用户授权调研“世界模型如何处理不同尺度的演化”，服务于“频段、尺度、任务结合”的子空间设计（见[讨论记录](../process/讨论记录.md)）。资料多为网页检索与 web-fetch 代理阅读，**阅读深度不一**，各条已标注；未本地保存原文。“对 EEG 的启示”均为助手推断，需用户判断。

## 1. 各工作要点

### H-JEPA（与本项目最接近）

- **出处**：Zhang, Terver, Rabbat, LeCun, Balestriero，“H-JEPA: End-to-End Learning of Hierarchical World Models for Visual Planning”，arXiv:2610.06805（v1 2026-10-05，v2 2026-11-01），预印本；代码 github.com/kevinghst/H-JEPA。**阅读深度**：v1 正文前约 40k 字符逐字，其余为模型摘要；v2 未读。
- **结构**：按时间分层。第 1 层处理最细的观测流；第 ℓ 层以步长 $s_\ell$ 取下层的潜变量（窗口 $w_\ell$ 个下层步汇总成一个上层状态）。**每层有自己的编码器、潜空间和预测器**（与先前共享潜空间的 HWM 不同）。实验中 $w_\ell=1$、$s_\ell=2$（或 3），即上层状态只做下采样，不做窗口池化。
- **目标**：每层 $\mathcal L^{(\ell)}=\mathcal L^{(\ell)}_{pred}+\lambda_\ell\,\mathrm{SIGReg}(Z^{(\ell)})$：一步潜在预测（MSE）+ LeJEPA 的 SIGReg 防坍缩；据摘要无 EMA 目标编码器、无 stop-gradient；**各层端到端联合训练**，上层梯度回传到下层编码器。
- **关键证据**：MLP 探测显示**层级越高，越丢弃快变特征、保留慢变特征**；而且这种“选择性抽象”**只在快慢成分的频率差距足够大（谱质心比约 ≥2 倍）时出现**，差距小于 2 倍的环境（Push-T、Cube、DROID）几乎没有。层数消融（摘要）：AntMaze 上 2/3/4 层成功率 39.3% / 73.3% / 63.3%。
- **作者承认的局限**：Push-T 三层以上效果差；上层看到的训练片段更少，各深度的计算量未匹配。

### Clockwork VAE（NeurIPS 2021，网页检索摘要）

层级循环潜变量，**每层以不同的“时钟”更新**，越往上越慢（时间抽象因子 2–8，指数递增）。实验显示慢层表示视频中变化慢的对象，快层表示变化快的对象；抽象因子越大，长程预测越准。目标为最底层重建 + 各层 KL。

### MTS3（NeurIPS 2023 spotlight，网页检索摘要）

多时间尺度状态空间模型：快、慢两个尺度各一个线性高斯 SSM，慢尺度潜变量耦合两层；快层捕捉短期趋势，慢层捕捉长期“任务”动态；可闭式推断。代码 github.com/ALRhub/MTS3。

### THICK（ICLR 2024 spotlight，网页检索摘要）

自适应时间抽象：下层（C-RSSM）只在时间上稀疏地更新部分潜变量（“上下文”）；上层预测上下文何时变化。上层学到类别化、可解释的时间抽象。

### 天气模型（网页检索摘要）

- **Pangu-Weather**：分层时间聚合——分别训练 1、3、6、24 小时预报模型，推理时组合使用，比单一步长迭代更稳定。
- **GraphCast**：在多尺度二十面体网格上做消息传递，空间多尺度。

### EEG 中的多尺度做法（已有笔记或检索摘要）

- **CSBrain**（已有笔记）：每层用 1/3/5 个片段的多尺度时间卷积 + 脑区内多尺度空间卷积；但时间尺度是“片段级”，不处理 1 s 内部。
- **REVE**（已有笔记）：4D Fourier 位置编码本身用多个频率编码坐标，可看作位置上的多尺度；但没有多分辨率池化。
- CoCoT-EEG、HCFT（检索摘要，未读）：多核卷积分支、金字塔式平均池化降低时间分辨率。
- DyWPE（检索摘要，未读）：基于小波分解的动态位置编码。

## 2. 对“尺度用位置编码 / 多尺度池化实现”的启示（助手推断）

用户的直觉是：尺度不划成独立子空间，而用位置编码或不同尺度的池化来表达。文献中有三种实现方式：

| 方式 | 代表 | 在 EEG 中的形态（推断） |
|---|---|---|
| **分层 + 步长下采样，每层独立潜空间与预测器** | H-JEPA | 第 1 层为 patch 级 token；第 2、3 层按步长池化后各自做潜在预测；可用 H-JEPA 的探测方法检验高层是否丢掉快变成分 |
| **不同更新速率（时钟）** | CW-VAE、MTS3 | 同一模型内设快、慢两类潜变量，以不同频率更新 |
| **尺度作为坐标进入位置编码** | 无直接先例 | 在 REVE 的 $(x,y,z,t)$ 之外增加一个“尺度”坐标，让不同池化尺度的 token 共用同一套 Fourier 位置编码 |

第三种与 REVE 的设计哲学（位置是坐标的函数）一致，且实现改动小，但没有文献直接验证。

## 3. 需要注意的耦合与约束（助手推断）

1. **尺度与频段有关，但不等价。**（2026-11-14 晚按合作者 review 更正；原说法“池化 / 下采样本身就是低通滤波，粗尺度层天然丢失高频”不准确。）
   - 对**原始波形**做长窗口平均，近似低通，40 Hz 振荡会正负抵消；但**下采样本身不是低通滤波**，没有抗混叠滤波时会产生混叠。
   - 对**能量、包络等局部表示**做长时间聚合，就保留了“高频活动强度如何随时间变化”。例如 $x(t)=A(t)\cos(2\pi\cdot40t)$：毫秒级的振荡波形、秒级的 γ 强度、更慢的强度趋势，都与同一个高频成分有关。
   - 因此**池化发生在什么表示上，比有没有池化更重要**。REVE 的 token 已经是 1 s patch 经编码器得到的潜在表示，在 token 层面池化，不等于对波形做低通；粗尺度层可以承载各频段（含 γ）的慢变化。H-JEPA 的“高层丢弃快变特征”指的是潜变量随时间变化的快慢，不是信号载波频率的高低。
2. **选择性抽象的前提是快慢成分差距足够大。** H-JEPA 发现频率差距 <2 倍时分层几乎无效。EEG 的 δ（<4 Hz）到 γ（>30 Hz）差距远大于此，这是支持在 EEG 上做分层的一条间接论据；但这只是推断，需要在 EEG 上测。
3. **输入长度限制层数。** 赛题 SSVEP 只有 1 s、自然刺激 2 s。若沿用 REVE 的 1 s patch，1 s 输入只有 1 个时间 token，无法分层；需要更短的 patch（如 EEGPT 的 0.25 s）或在 patch 内部做多尺度。
4. **防坍缩。** H-JEPA、LocaLeJEPA 都用 SIGReg 系列正则；JEPA-Anything 用方差 hinge；EEGPT 用 EMA 目标编码器。分层后每层都需要防坍缩。
