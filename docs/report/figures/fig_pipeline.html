两阶段研究流程：复赛回答问题，决赛按答案设计
复赛基于 REVE 公开权重（MIT 许可）；决赛按规则不加载任何权重，在官方 21 个 OpenNeuro 数据集上从零预训练
复赛（约 11/23–12/6）
第 0 步　诊断（RQ1，不训练）
① 层 × 频段 × 尺度的可恢复性图
　（用描述子探测冻结的 REVE）
② 读出瓶颈：线性 / PCA / 多项式 / MLP
③ REVE 官方流程基线：14 数据集 × 3 种子
第 1 步　继续预训练（RQ2）
数据：下游训练集被试，不用标签
　验证 / 测试被试不进入；必要时按种子分别训练
阶段 1：冻结编码器，热身新增模块
阶段 2：解冻，按层衰减学习率；
　每 batch 随机抽 patch 长度组合
第 2 步　下游适配
任务门控 + 分类头
先冻结训练门控与头，再全量微调 / LoRA
读出方式、patch 组合按验证集 BACC 选
3 个种子，报告 BACC 等 4 项指标
消融与可解释性（RQ2、RQ3）
A1 只用原目标继续预训练（关键对照）
A2 全锚定　A3 全自由　A4 无正交
A5–A7 patch 与跨尺度注意力
A8 门控　A9 防遗忘方式
带限扰动、自由子空间探测、门控权重
由复赛结果决定决赛设计
判读规则（见 5.3）
· 锚定子空间稳定有效、自由子空间贡献小 → 决赛提高锚定比例（数据更少，先验更有价值）
· 自由子空间有贡献且不能被已知描述子解释 → 保留较大自由子空间，作为“超出先验”的证据
· 跨尺度注意力只对短时任务有效 → 决赛只为这些输入长度启用短 patch
· 瓶颈主要在读出 → 决赛侧重门控与读出层选择
· 完整方法 ≈ A1 → 收益来自领域适应，决赛退回更简单的方案
决赛（约 12/14–27）：从零预训练
语料：官方 21 个 OpenNeuro 数据集，32/64/76/128 通道，200 Hz，已与下游被试隔离
模型：REVE 式编码器（坐标式 4D 位置编码、块状掩码），规模在 Small 12M 与 Base 69M 之间按算力选择
目标：锚定 / 自由子空间比例与各损失权重取自复赛；𝓛keep 换为 L1 波形重建
适配：与复赛相同的任务门控与两段式微调
