## 一、项目背景与目标

本项目围绕 **OmniEEG Challenge 2026** 展开，该比赛考察 EEG 基础模型在跨被试、跨数据集、跨任务场景下的泛化能力。比赛共设 7 个分赛道，每道 2 个数据集；主赛道覆盖全部分赛道。

当前处于 **初赛阶段**（截至 2026-11-15）。初赛仅需提交研究方案 PDF 和 PPT，不要求代码、权重或已完成实验。符合要求的队伍超过 64 支时按评分排序晋级。从 200 余支参赛队伍中脱颖而出，取决于参赛者自身的理解深度、问题意识和方案叙述能力。

## 二、协作原则

1. **用户主导**：内容推进和研究方向的选定由用户决定，助手负责解释、核对和讨论，不代替用户形成判断。
2. **不提前替用户做完**：若方案完全由助手生成而缺乏用户的理解，反而会增加不确定性和风险。助手的建议须供用户理解和质疑。
3. **以问题驱动研读**：围绕用户选择的具体问题逐篇深入，而非横向概括取代精读。
4. **不锁定技术路线**：当前不预设 REVE 残差分支、固定卷积核或训练预算等具体方案。用户对 REVE 的关注属于研究兴趣，并不等于已选定任何改进模块。

## 四、文档规范要点

- 每篇论文笔记需覆盖：问题定义、输入输出张量、前向计算模块链路、训练阶段与损失、实验证据定位、局限与未读懂之处。
- 统一符号：$B$ 批次、$C$ 通道、$T$ 采样点、$N$ 时间 token、$D$ 表示维度。
- 严格区分作者报告结果、独立 benchmark 结果与自测结果；不以跨协议的数值差异论证架构优劣。
- 公开结果存在明显的协议依赖性，阅读时按需取证，避免重新下载全部资料。

## 五、版本控制与撤回记录

- **初始快照**：提交 `bf4044b`，保存了全部现有内容。
- **撤回内容**：第二次提交删除了助手提前生成的路线、实验计划、预设阅读/训练顺序及相关报告，并清理了引用关系。
- **保留内容**：论文事实、原始来源、评测数据全部保留。
- **远程仓库**：GitHub `Wang-Shinan/OmniEEG`（私有）。最终状态以 Git 记录为准。

## 六、接续工作指引

1. 沿用户的下一条消息继续讨论，不自动恢复已撤回的路线或计划。
2. 围绕用户提出的问题展开研读与解释，跟随而非引导。
3. 建议须附证据且可由实验否定，不做不可检验的断言。
4. 如有新的比赛通知，更新赛题文档正文并在决策记录中注明变更来源与影响。
5. 初赛尚未生成正式参赛 PDF/PPT，也未发送提交邮件——这些步骤须在用户确认后推进。
