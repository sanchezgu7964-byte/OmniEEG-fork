## 2. 润色要做的事

1. **讲故事。** 用户认为当前稿“很不讲故事”。助手曾提出一条故事线（用户尚未确认，可作起点，最终由用户定）：
   - **悬念**：同一个 REVE，SSVEP 96%、运动想象第一，精神分裂症却只有 44%，输给小型专用网络——我们不知道基础模型学到了什么（用户原话：“大家都不知道自己在做什么”）。
   - **解释（假设）**：EEG 的关键信息分布在不同频段和时间尺度上，现有模型把它们混在一个向量里（FAME 的低频偏置、固定 1 s 窗口、Neuro-KE 指出的生理结构丢失），任务需要的信息落在被忽视的频段或尺度时就会掉分，而且查不出原因。
   - **回应**：给表征一套“频段 × 尺度”的地址系统——REVE 用电极坐标让 token 知道自己在头皮哪里；我们让表征知道信息属于哪个频段、哪个尺度。锚定子空间 = 已知地址（先验），自由子空间 = 未知地址（超出先验），可变 patch + 跨尺度注意力 = 各尺度都有地址且互通，任务门控 = 各任务自选地址。
   - **验证**：先画 REVE 现有的地址图（诊断）→ 加地址系统（改进）→ 看各任务选了哪些地址是否符合生理规律（回答开头的悬念）。
   - **延续**：复赛告诉我们哪些地址该预设、哪些该留给模型学，决赛照此从零训练。
2. **精简。**
   - 动机只用两三个最有冲击力的事实开场，其余证据进表格或第 3 块；
   - 相关工作每节收在“所以还缺什么”；
   - 方法先讲想法，再讲部件；
   - 少用条列。
3. **去掉起草标记。** 【用户判断】【助手推断】【用户与合作者讨论的结论】只是起草标记，正式稿删除（构建脚本 `--clean` 会自动去掉这些标记和文首的状态框）。【待定】【待确认】不能直接删，见第 5 节。
4. **统一术语。** 包括：平衡准确率（BACC）、线性探测、全量微调、继续预训练、锚定子空间、自由子空间、跨尺度注意力、任务门控。
5. **篇幅。** 手册的章节与页数只是建议格式，不是硬性要求。评审按评分项找证据，建议模块标题保留与评分项一一对应（见 `docs/competition/报告模块结构.md`）。

## 3. 不要改的东西

**已定决策**（来源：`docs/process/决策记录.md`、`docs/process/讨论记录.md`）：

- 主赛道；方案覆盖复赛与决赛两阶段；“先诊断，后改进”；
- 复赛在 REVE 公开权重上**继续预训练**，分数优先；决赛按规则从零预训练（21 个官方 OpenNeuro 数据集）；
- 子空间采用**混合方案**：频段锚定子空间（以描述子为目标）+ 自由子空间（潜在预测，不预设含义）；
- “任务”指比赛下游任务：任务不占子空间，通过门控读取“频段 × 尺度”；
- 尺度不单独划分子空间：由可变长度 patch 与潜在 token 聚合产生，尺度嵌入只标明范围；
- 不同长度 patch 通过（门控）交替注意力共享信息；
- 贡献来自方法而非推翻架构；
- Neuro-KE 是对“表征问题”的回应（描述子既用于诊断也用于改进）；
- NeuroLM / UniMind / ECHO 是“有趣但竞争力不足”的强解码器分支。

**数字与可比性**：

- 不改任何数字；如果觉得有误，标出来交给用户或回查原文。
- 图 5 汇集了不同协议的 SSVEP 结果，只用于说明“分数主要由协议决定”，**不得**改写成排行榜。
- 不同论文、不同协议的分数不能直接比较优劣（评审细则的扣分点）。
- 第 7 节只能写“暂无已完成实验结果”，不填预期数值。

**审核红线**（手册）：

- 不能只堆技术名词；
- 不能直接套用通用模型而无针对 EEG 的改进（因此“为什么适合 EEG”的论证不能被删弱）；
- 不能使用未披露的私有数据。

## 7. 构建方法

```bash
# 准备 mermaid（正文已不含 mermaid 图，但脚本需要该文件路径）
mkdir -p /tmp/mm && cd /tmp/mm && npm pack mermaid@10.9.1 && tar xzf mermaid-10.9.1.tgz
cd <仓库根目录>
# 数据图（改 build/make_charts.py 后重跑）
python3 docs/report/build/make_charts.py
# SVG / HTML 示意图 → PNG（2 倍分辨率，PPT 用）
cd docs/report/figures && node ../build/svg2png.js *.svg fig_method_arch.html fig_pipeline.html && cd -
# PDF：--clean 去掉起草标记与状态框
python3 docs/report/build/build_pdf.py docs/report/初赛报告草稿.md docs/report/正式稿.pdf /tmp/mm/package/dist/mermaid.min.js --clean
```

依赖：pandoc 3.x；Node 版 Playwright 与 Chromium（`require('playwright')` 可用）；字体 Inter、WenQuanYi Zen Hei。
