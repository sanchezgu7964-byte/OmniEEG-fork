## 2026-11-14 晚：合作者 agent 的 review

用户转来合作者 agent 的 review，要点：
1. 频段与尺度有关但不等价（如 $A(t)\cos(2\pi\cdot40t)$：高频成分也有慢时间尺度的结构）；“粗尺度层天然丢失高频”需限定——池化发生在什么表示上比有没有池化更重要；下采样本身不是低通，可能混叠。
2. 尺度编码（标明观察范围）与多尺度聚合（产生不同范围的表示）作用不同；只加尺度数值不产生多尺度信息。
3. 频段与任务的划分依据不同（信号属性 vs 使用目的），不宜设为互斥的存储位置；两种理解：(1) 频段子空间组织基本表征，任务以不同组合读取；(2) 另学任务相关的高层子空间。
4. 正交（点积为零或协方差小）不自动意味着对应纯粹的频段或任务因素；强制独立可能压掉有用的关联。
5. 提问：“任务子空间”更接近“各任务各有一部分表示”，还是“可被不同任务复用的表示因素”。

助手处理：采纳 1、2、4，更正[多尺度调研](../reviews/多尺度演化建模调研.md) §3.1 与 [REVE 改造地图](../reviews/REVE改造地图.md) §3 中的错误说法；关于 3、5，用户此前确认的含义（任务决定每个数据集用哪些频段、哪些尺度）对应 review 的理解 (1)，即任务不占子空间、通过读出连接。待用户确认。
